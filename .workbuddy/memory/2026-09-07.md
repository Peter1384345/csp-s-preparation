
## 部署 CSP-S 备考站到 GitHub（gh CLI 未安装，改用 git + REST API）
- 仓库：https://github.com/Peter1384345/csp-s-first-round （public，main 分支）
- deploy/ 目录：index.html + papers/(10) + md + README.md + LICENSE
- 环境坑：
  1. gh CLI 未安装；`git credential fill` 可用时拿到的 token 对 REST API 401（Bad credentials）
  2. 本机有 HTTPS 拦截证书：curl 必须 `-k`、git 必须 `-c http.sslVerify=false`，否则 schannel CRYPT_E_NO_REVOCATION_CHECK
  3. GCM 无缓存凭据时会尝试交互式登录，命令被 SIGTERM 杀掉；解决：把 push 放 run_in_background，让它弹窗等用户登录
  4. 远端 ref 不落盘（.git/refs/remotes 消失），用 curl -sk api.github.com 匿名核对状态更可靠
- LICENSE 必须为标准 MIT 纯文本（追加自定义段落会让 GitHub 识别为 NOASSERTION），试题版权说明放 README
