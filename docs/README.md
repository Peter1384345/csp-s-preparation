# CSP-S 第一轮备考全攻略

面向 CSP-S（提高级）第一轮认证（笔试）的开箱即用备考站：**近 5 年真题 PDF + 在线刷题 + 考点频次统计 + 两轮认证对比**，全部本地运行、零依赖、可离线使用。

> 2026 年 CSP-S 第一轮认证时间：9 月 19 日 14:30–16:30

## 快速开始

**本地使用（推荐）**：克隆或下载本仓库后，直接双击 `index.html` 即可——无需服务器、无需安装任何东西，断网也能完整使用。

```bash
git clone https://github.com/Peter1384345/csp-s-first-round.git
# 然后打开 index.html
```

**在线访问**：开启 GitHub Pages 后可在线浏览——仓库 **Settings → Pages → Deploy from a branch → 分支选 `main`、目录选 `/ (root)` → Save**，约 1 分钟后访问：

<https://peter1384345.github.io/csp-s-first-round/>

## 功能一览

| 板块 | 内容 |
|---|---|
| 真题 PDF | 2021–2025 近 5 年第一轮真题及答案（本地直开，含 45 页复习资料与备考指南） |
| 在线刷题 | 内嵌 30 道真题单选（2024–2025 全部），即时判分 + 三段式深度题解（考点定位 / 解题过程 / 易错提醒） |
| 错题本 | 做错的题自动收入，支持错题重刷，localStorage 持久化 |
| 学习统计 | 按考点统计正确率，定位薄弱环节 |
| 限时模考 | 20 分钟倒计时，交卷判分并折算 30 分制 |
| 考点频次 | 2021–2025 共 75 道选择题逐题统计，T0/T1/T2 三级优先级 |
| 阅读程序 / 完善程序 | 六大代码模式 + 五大算法家族拆解 |
| 两轮对比 | 第一轮笔试 vs 第二轮上机所需能力的差异清单 |
| 学习路线 / 方法论 | 按目标分层的路线与选题、错题归因方法 |

## 推荐使用节奏

1. **摸底**：在线刷题 → 按年份做 2025 全套
2. **诊断**：学习统计面板查看薄弱考点
3. **补漏**：对照 T0/T1/T2 重点清单 + 45 页复习资料补知识
4. **巩固**：错题重刷清零
5. **实战**：考前一周用限时模考卡时间训练手感
