到上一页为止，初赛的「考什么、怎么练、怎么考」已经完整；本页把视线拉远——第一轮只是门票，第二轮才是颁奖依据。

两轮考试形式、评分与核心能力差异很大，理解这些差异，才能在笔试结束后的第二天就走对下一步。

两轮认证对比第一轮笔试与第二轮上机，考的是两种不同的能力

维度第一轮（笔试）第二轮（上机）
形式集中笔试（部分区域机试），纸质答题卡现场集中上机，NOI Linux / Windows 环境
时间9 月第三个周六 14:30–16:30，共 120 分钟10 月下旬周六 14:30–18:30，共 4 小时
题型15 道单选（30 分）+ 3 道阅读程序（40 分）+ 2 道完善程序（30 分）4 道编程题，每题 100 分，共 400 分
评分按答案对错给分，一锤定音每题 10–25 个测试点部分给分，暴力也能拿分
门槛人人可报，是晋级第二轮的门票（须达各省分数线）须第一轮达线方可参加，获奖只看第二轮成绩
核心能力知其然：理论判断、细节辨析、人肉追踪代码写得出：算法设计、代码实现、调试与骗分策略

第一轮要掌握的以"识别与判断"为标准

T0 组合数学（排列组合、不相邻、隔板法）、图论理论（遍历、连通性、树与生成树计数）、复杂度计算

T1 进制与编码（原码/反码/补码、ASCII、进制转换）、位运算与逻辑运算优先级、数据结构性质（栈/队列/链表/二叉树/哈夫曼）、C++ 语法细节、计算机史与硬件常识

独有 人肉模拟程序运行——在草稿纸上列表格追踪变量变化，这是阅读程序题 40 分的全部基本功，机器永远代替不了你

第二轮要掌握的以"独立写出完整程序"为标准

T0 基础算法实现：枚举、模拟、贪心、二分、DFS/BFS 与剪枝、前缀和与差分

T1 动态规划（背包、区间、线性、树形）、图论算法（最短路 Dijkstra/SPFA、最小生成树、拓扑排序）、数据结构编码（STL 熟练、并查集、树状数组、线段树）、简单数论

独有 工程能力：文件 IO（freopen）、对拍造数据、部分分策略（先写暴力再优化）、卡常与防爆内存——这些在笔试里完全不考

策略提示：本页（真题 PDF / 在线刷题 / 考点清单 / 阅读与完善程序训练）全部面向第一轮。两轮能力清单交集不大——第一轮高分不等于第二轮稳拿奖；反之第二轮选手也常因理论细节在第一轮翻车。建议第一轮通过分数线后，立即转入洛谷等平台按第二轮算法清单刷题。

两轮衔接行动清单笔试当晚就该做的事

① 笔试结束当晚：不对答案、不纠结，给自己放一晚假——第一轮已结束，沉没成本不再投入。

② 出分达线后立即转段：按本页第二轮 T0/T1 清单，到洛谷等平台按算法标签系统刷题；第一轮积累的完善程序模板（最短路、DP）会原样复用。

③ 心态校准：第一轮高分 ≠ 第二轮稳拿奖（能力交集不大），反之第二轮选手也常因理论细节在笔试翻车——两个清单都要过，只是先后不同。
